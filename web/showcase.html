One-tap sign-in

Google or Microsoft Entra ID through the Cognito Hosted UI with PKCE. Every identity becomes one account ID.

Voice and background push

A service worker receives Web Push (VAPID) even with the tab closed. Natural speech comes from Supertone Supertonic running on GCP.

Layered abuse protection

Regex, a gate before Bedrock, then Claude itself. Three strikes means a temporary ban, stored per account so switching devices does not help. Logs are JSON and never contain prompt text.
