# 🦘 FunReminder - Your Aussie Reminder

A fun alarm app: enter a **time** and a **reminder message**, and when the time comes, FunReminder goes off with your reminder plus an **Aussie idiom** generated by AI.

🌐 **Live demo:** http://reminderyoubro.s3-website-ap-southeast-2.amazonaws.com/

## ✨ Features

- Set an alarm by entering a time and a reminder message.
- When the alarm fires, it plays a random Aussie idiom generated by Claude Haiku 4.5 via Amazon Bedrock.
- Infrastructure is fully managed as code (Terraform) and deployed automatically (GitHub Actions).
- Serverless architecture with no servers to manage.

## 🏗️ How it works

1. The user opens the web app (hosted on S3) and enters a time and a reminder message.
2. The app calls API Gateway, which routes to Lambda to save the alarm in DynamoDB and schedule it with EventBridge.
3. When the time comes, EventBridge triggers Lambda.
4. Lambda reads the alarm from DynamoDB and calls Claude Haiku 4.5 via Bedrock to generate an Aussie idiom.
5. The alarm goes off with the reminder message and the idiom.

## 🔐 Security

All security configuration (least-privilege IAM roles, S3 access policies, Bedrock invoke permissions, etc.) is defined in Terraform and applied automatically through GitHub Actions, so every change is transparent and reviewable.

## 🚀 Deployment

### Prerequisites

- An AWS account (region `ap-southeast-2`, Sydney) with access to Claude Haiku 4.5 enabled in Bedrock
- [Terraform](https://developer.hashicorp.com/terraform/install)
- AWS CLI with configured credentials

### Manual deployment

```bash
cd terraform
terraform init
terraform plan
terraform apply
```

### Automated deployment

On every push to the main branch, GitHub Actions runs a pipeline that validates and applies the Terraform configuration. Set up the AWS secrets or OIDC role in your repository settings first.
